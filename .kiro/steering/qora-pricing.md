## 3 REVENUE STREAMS

### Stream 1 — Subscription (Base)
- Flat monthly = predictable MRR
- Simple for customer to understand

### Stream 2 — Usage Overage (Expansion)
```
Customer grows naturally:
Month 1:  ₹799 base
Month 6:  ₹799 + ₹200 overage = ₹999
Month 12: ₹799 + ₹500 overage = ₹1,299
```
Automatic revenue growth without new customers = "Net Revenue Retention > 100%" = investors love it

### Stream 3 — Add-ons
- WhatsApp, BYOC, custom domain = high margin
- One BYOC deal (₹49,999/yr) = 5 years of Starter subscription value

## VALUATION FORMULA
```
MRR × 100 = rough SaaS valuation (standard rule)

₹1 lakh MRR   = ₹1 crore valuation
₹10 lakh MRR  = ₹10 crore valuation
₹1 crore MRR  = ₹100 crore valuation

Usage-based billing = higher multiplier from investors
```

## FREE TIER STRATEGY (Lock-in Logic)
1. Give enough to build real product → user gets addicted
2. 500K vectors = 50K docs = enough for real production app
3. 1K queries/day = ~200 daily users → startup grows → natural upgrade
4. Collections unlimited = more data stored = harder to migrate
5. Easy export = TRUST = user stays because they WANT to, not trapped
6. Migration cost: 500K vectors = significant work = user won't move
